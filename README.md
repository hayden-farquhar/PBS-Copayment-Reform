Analytical code for: **"Australia's 2023 PBS copayment reduction did not increase prescription dispensing: a natural-experiment evaluation and a cautionary tale for policies timed to 1 January"**

**Contact:** hayden.farquhar@icloud.com
**ORCID:** 0009-0002-6226-440X

## Overview

This repository contains the data acquisition, cleaning, and analysis scripts to replicate all findings reported in the manuscript. The study evaluates Australia's January 2023 reduction in the Pharmaceutical Benefits Scheme (PBS) general patient copayment from $42.50 to $30.00, using more than two decades of national dispensing data (May 2002–December 2025).

Identification rests on an **event-study / dynamic difference-in-differences** design (treated = general/19–64 dispensing, control = concessional/65+ dispensing), with a **triple-difference (DDD)** estimator as the keystone class-level specification. Supporting analyses establish that the copayment cut was delivered to patients (a first-stage out-of-pocket-cost reduction of about $3.19 per general script), that there is no dose-response across pre-reform price exposure, and that the null survives de-seasonalisation, pre-period anchor sensitivity, HonestDiD partial-identification bounds, and placebo-in-time tests. The headline result is **no detectable change in dispensing** (a calibrated null): the level estimate is bounded small, the response shows no gradient with price exposure, and the turn-of-year movement is the ordinary annual safety-net reset, consistent with price-inelastic demand. A **distributional (equity) re-estimation** (`09_equity_reestimation.R`, with an anchor-robustness diagnostic in `09b_equity_artefact_diagnostic.R`) finds no robust differential benefit by socio-economic disadvantage or remoteness, and `08_event_study_did.R` includes a **60-day-dispensing robustness** check on a window that fully predates the September 2023 rollout. Scripts `03_its_analysis.R`, `04_causal_impact.R`, and `05_equity_analysis.R` reproduce the earlier interrupted-time-series, Bayesian structural-time-series (CausalImpact), and equity analyses; they are retained for transparency but are not part of the current paper's identification, which rests on `08_event_study_did.R` and the distributional re-estimation (`09`/`09b`).

## Replication Instructions

Scripts are numbered sequentially and should be run in order from the project root directory.

### Step 1: Data Acquisition

```r
source("scripts/01_data_acquisition.R")
```

This downloads ABS data files (SEIFA, Remoteness Areas, LGA shapefiles, ERP) automatically. **AIHW PBS data requires manual download** — the script prints instructions:

1. Go to https://www.aihw.gov.au/reports/medicines/pbs-monthly-data/data
2. Download all supplementary Excel workbooks (ATC Level 1 and Level 2, historical and current)
3. Save `.xlsx` files to `data/raw/`

Expected files in `data/raw/` after this step:
- `AIHW-HWE-098-PBS-ATC1-prescriptions-historical-data.xlsx`
- `AIHW-HWE-098-PBS-ATC1-prescriptions-monthly-data.xlsx`
- `AIHW-HWE-098-PBS-ATC2-prescriptions-historical-data.xlsx`
- `AIHW-HWE-098-PBS-ATC2-prescriptions-monthly-data.xlsx`
- `SEIFA_2021_LGA.xlsx`
- `RA_2021_AUST.xlsx`
- `LGA_2021_AUST_allocation.xlsx`
- `MB_2021_AUST.xlsx`
- `ERP_LGA_2001_2024.xlsx`

### Step 2: Data Cleaning

```bash
source .venv/bin/activate
python scripts/02_data_cleaning.py
```

Processes raw Excel workbooks into tidy monthly panel CSVs:
- `data/processed/pbs_national_monthly.csv` (~8 MB)
- `data/processed/pbs_state_monthly.csv` (~56 MB)
- `data/processed/pbs_lga_monthly.csv` (~2.9 GB)
- `data/processed/lga_characteristics.csv`
- `data/processed/erp_lga.csv`

### Step 3: Descriptive Analysis

```r
source("scripts/01b_descriptive_analysis.R")
```

Produces descriptive time series plots and summary statistics (Table 1 inputs, Figure 1).

### Step 4: Interrupted Time Series

```r
source("scripts/03_its_analysis.R")
```

Segmented regression with Newey-West HAC standard errors across 86 ATC Level 2 classes. Produces ITS results tables and forest plots.

### Step 5: Bayesian Causal Impact (supporting triangulation)

```r
source("scripts/04_causal_impact.R")
```

CausalImpact models using concessional (65+) prescriptions as a control series. Produces a supporting structural-time-series estimate and ATC-level/state-level stratifications. This is a triangulation method; primary identification is the event-study / triple-difference design in Step 8.

### Step 6: Equity Analysis

```r
source("scripts/05_equity_analysis.R")
```

Difference-in-differences panel regression by SEIFA quintile and remoteness category, triple-difference test, equity impact ratios, spatial autocorrelation (Moran's I), and choropleth maps.

### Step 7: Sensitivity Analyses

```r
source("scripts/07_sensitivity.R")
```

Six robustness scenarios: 60-day dispensing adjustment, COVID-19 exclusion, placebo intervention dates, shortened pre-period, control correlation filtering, and alternative equity windows.

### Step 8: Event Study & Triple-Difference (primary identification)

```r
source("scripts/08_event_study_did.R")
```

The primary identification analysis. Builds:

- **Event-study / dynamic DiD** (`fixest::feols`, unit fixed effects = LGA × age group, time fixed effects = calendar month). The month fixed effects absorb national shocks (including COVID-19 waves) non-parametrically; pre-reform event-time coefficients provide a joint parallel-trends test.
- **Triple-difference (DDD)** across the 86 ATC Level 2 classes, differencing out general-arm January seasonality and class-specific shocks. This is the keystone class-level estimator.
- **First stage**: the realised out-of-pocket-cost reduction per general script (about $3.19), with a concessional placebo.
- **Dose-response** across pre-reform price exposure (zero slope).
- **De-seasonalisation** against the pre-period LGA × arm × calendar-month mean.
- **Pre-period anchor grid** (sensitivity of the estimate to baseline-period choice).
- **HonestDiD** relative-magnitudes partial-identification bounds (Rambachan & Roth).
- **Placebo-in-time** reassignment of the intervention date.

Run after Step 6. Produces the main-text event-study and DDD figures plus supporting robustness tables, including a **60-day-dispensing robustness** check (Section 9b) that re-estimates on a January–August 2023 window fully predating the September 2023 rollout (`outputs/tables/sixty_day_robustness.csv`).

### Step 9: Distributional (equity) re-estimation

```r
source("scripts/09_equity_reestimation.R")
source("scripts/09b_equity_artefact_diagnostic.R")
```

Re-estimates the general-versus-concessional difference-in-differences separately by SEIFA disadvantage quintile and by Remoteness Area, on the de-seasonalised clean window, and applies a per-stratum pre-period anchor diagnostic (`09b`). The result is no robust differential benefit: apparent positives in disadvantaged and remote strata sign-flip across baselines. This corrected re-estimation supersedes `05_equity_analysis.R` for the current paper.

## Notes

- R scripts use `here::here()` for path resolution. Open the project as an RStudio project or ensure `.git` is in the root directory.
- The Python script resolves paths relative to its own location (`scripts/` → project root).
- The LGA-level processed CSV (`pbs_lga_monthly.csv`, ~2.9 GB) is not tracked by git due to file size. It is regenerated by `02_data_cleaning.py`.
- Runtime for the full pipeline is approximately 2-3 hours, with the majority spent on CausalImpact MCMC fitting (Step 5) and the equity bootstrap (Step 6).
